# Bulk RNA-seq Analysis

This repository contains a complete bulk RNA-seq analysis workflow including:

- Quality Control (FastQC & MultiQC)
- Salmon Quantification
- Differential Expression Analysis using DESeq2
- PCA Analysis
- Volcano Plot
- Pathway Analysis

## Repository Structure

- `data/` : count matrix, metadata, pc_gene.txt
- `scripts/` : analysis scripts (.Rmd, .py, .sh)
- `results/` : plots, csv outputs, QC reports, workflow screenshots

## Tools Used

- FastQC
- MultiQC
- Salmon
- R / DESeq2
- Python
